# React Native adapter

Future npm package `@tugboat/react-native`. Not implemented yet.

The adapter runs on the native Android and Swift SDKs in this repository.
During development it builds against the in-repo native SDKs; its release
depends on the published Android SDK (Maven Central) and Swift SDK (SwiftPM
and CocoaPods). Raw pixels never enter JavaScript. There is no npm workspace
in this repository yet.
