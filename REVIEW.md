# Review guide

The review agent reads this file from the default branch on every review. Keep it
short, and move repeated review comments here. Changes to it need a person's approval.
See blendto/review-agent's README for examples of what to write.

## Findings

- Every finding needs a file and line as evidence, not a guess from a name.
- At most three nits per review.
- When there's nothing to fix, say so plainly.
